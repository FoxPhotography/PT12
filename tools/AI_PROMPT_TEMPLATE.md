# البرومبت الثابت لإضافة مواد جديدة (AI Prompt Template)

**استخدم هذا البرومبت في أي محادثة مع الذكاء الاصطناعي (مثل ChatGPT أو Claude) عندما تريد إضافة مادة جديدة لتطبيقك:**

---

**انسخ النص التالي وألصقه للذكاء الاصطناعي مع إعطائه المادة (الأسئلة أو التلخيص):**

أريدك أن تقوم بتحويل المادة العلمية المرفقة إلى ملف JSON مهيكل بدقة ليعمل مع تطبيقي (React + TypeScript). 
التطبيق يدعم نوعين من المواد: "أسئلة اختياري (MCQ)" و "مراجعة شاملة (Revision)".

أولاً، حدد نوع المادة.

**إذا كانت المادة (أسئلة MCQ):**
قم بتوليد JSON بهذه الصيغة بدقة:
```json
{
  "id": "unique_course_id",
  "title": "اسم المادة (مثل Physiology CNS)",
  "category": "final أو oral أو midterm",
  "type": "mcq",
  "description": "وصف قصير",
  "icon": "أيقونة إيموجي مناسبة",
  "stats": {
    "questions": عدد_الأسئلة_هنا,
    "topics": عدد_المواضيع_هنا
  },
  "questions": [
    {
      "q": "نص السؤال هنا؟",
      "options": ["الخيار الأول", "الخيار الثاني", "الخيار الثالث", "الخيار الرابع"],
      "correctIndex": رقم_الخيار_الصحيح_يبدأ_من_صفر,
      "topic": "اسم الموضوع أو الشابتر"
    }
  ]
}
```

**إذا كانت المادة (مراجعة/تلخيص Anatomy أو غيره):**
قم بتوليد JSON بهذه الصيغة:
```json
{
  "id": "unique_course_id",
  "title": "اسم المادة (مثل Anatomy Revision)",
  "category": "final أو oral أو midterm",
  "type": "revision",
  "description": "وصف قصير",
  "icon": "إيموجي",
  "sections": [
    {
      "title": "اسم القسم",
      "icon": "إيموجي",
      "content": "نص المراجعة هنا بصيغة HTML (انظر قواعد التصميم بالأسفل لجعله ملوناً واحترافياً)."
    }
  ],
  "flashcards": [
    {
      "q": "سؤال سريع للفلاش كارد؟",
      "a": "الجواب القصير"
    }
  ]
}
```

**قواعد هامة جداً للتصميم والمحتوى (CSS Layout):**
1. **للمراجعات لا تستخدم Markdown عادي:** بل استخدم HTML لتنسيق المحتوى بألوان احترافية.
2. **الكروت (Cards):** ضع كل فقرة رئيسية داخل `<div class=\"content-card\">...</div>`.
3. **العناوين الفرعية:** استخدم `<div class=\"subsection-title\">...</div>` لعناوين الدروس أو المواضيع داخل الكارت.
4. **مربعات الملاحظات الملونة:** استخدم `<div class=\"highlight-box blue\">...</div>` (الألوان المتاحة: `blue`, `cyan`, `green`, `yellow`, `purple`). وضع بداخلها عنوان `<div class=\"hb-title\">العنوان</div>` يليه النص.
5. **القوائم المنظمة:** استخدم `<ul class=\"info-list\">...</ul>` للنقاط الهامة، وللترقيم استخدم `<ul class=\"info-list numbered\">`.
6. **الجداول:** استخدم `<table class=\"compare-table\">` لجداول المقارنة، واستخدم `<table class=\"muscle-table\">` لأي جداول تحتاج تمييز العمود الأول (مثل العضلات أو الأعصاب).
7. **التاجات الملونة للكلمات (Tags):** لتلوين الكلمات الطبية استخدم:
   - `<span class=\"vein-tag\">...</span>` (أحمر)
   - `<span class=\"artery-tag\">...</span>` (برتقالي)
   - `<span class=\"nerve-tag\">...</span>` (بنفسجي)
   - `<span class=\"tube-tag\">...</span>` (سماوي)
   - `<span class=\"lymph-tag\">...</span>` (أخضر)
8. تأكد من عمل Escape صحيح لعلامات التنصيص `"` داخل محتوى الـ HTML كالتالي: `<div class=\"content-card\">`.
9. تأكد من أن ملف الـ JSON صالح تماماً (Valid JSON).
