# PT Exam Hub (PT12)

دليل ومنصة امتحانات وبنك أسئلة العلاج الطبيعي (Physical Therapy) — شيتات وأسئلة الميدتيرم، الفاينال، والشفوي.

---

## 📂 هيكلة المنصة (Structure)

- **`index.html`**: البوابة الرئيسية التفاعلية للمنصة.
- **`year-2/`**: امتحانات وأسئلة الفرقة الثانية (Anatomy, Biomechanics, Electrotherapy, Exercise Physiology, Manual Therapy, Muscle Test, Physiology CNS, Therapeutic Exercise).
- **`year-3/`**: امتحانات وأسئلة الفرقة الثالثة (Cardiopulmonary PT - CVP, Immunology).
- **`data/`**: المواد والملفات المرجعية (PDFs).
- **`tools/`**: أدوات ومولدات الأسئلة التلقائية.

---

## 🚀 النشر على Vercel (Vercel Deployment)

المشروع عبارة عن **Static HTML Site** فوري بدون أي Build Step:
1. اربط الريبو على Vercel: `FoxPhotography/PT12`
2. **Framework Preset**: اختر **Other** (أو Static).
3. **Root Directory**: `./`.
4. اضغط **Deploy**.
